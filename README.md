# AllSafe

AllSafe Cybersecurity 🔐

A beginner-level Python cybersecurity project that simulates a secure network login system.

FEATURES

- Username and password authentication
- Department-based access control
- Security, HR and Management departments
- Unauthorized-user detection
- Failed login attempt tracking
- Brute-force attack detection
- ASCII alert display
- Logout functionality
- "try-except" input validation

PYTHON CONCEPTS PRACTICED

- Dictionaries
- Functions
- "if / elif / else"
- "while" and "for" loops
- "break" and "return"
- "try-except"
- Boolean and logical operators
- Dictionary keys and values

PURPOSE

This project was built to strengthen my Python skills while applying them to a practical cybersecurity scenario.
